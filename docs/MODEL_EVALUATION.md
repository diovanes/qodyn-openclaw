# Avaliação com modelo

O template usa testes estáticos por padrão. Para avaliação real:

- fixe provedor, modelo e parâmetros;
- sanitize o dataset;
- limite custo e timeout;
- use saída estruturada;
- avalie por rubrica;
- compare com baseline;
- exija revisão humana em mudanças críticas.

Não use igualdade literal de texto como critério principal.
