# Guia de escrita

## AGENTS.md

Use para missão, prioridades, fluxo geral e guardrails.

## SOUL.md

Use para voz, personalidade e comportamento conversacional.

## Skills

Use para processos específicos, checklists, ferramentas e tratamento de falhas.

## Regra de qualidade

Uma regra deve indicar gatilho, ação, exceção, falha e critério de conclusão.

## Antipadrões

- regras vagas;
- contradições;
- segurança apenas textual;
- detalhes temporários no prompt permanente;
- duplicação excessiva;
- prompts gigantes.
