# Solicitação estruturada

1. Resuma o objetivo.
2. Liste requisitos explícitos.
3. Identifique restrições e critérios de aceite.
4. Resolva suposições seguras.
5. Marque lacunas essenciais.
6. Entregue resultado e limitações verificáveis.
