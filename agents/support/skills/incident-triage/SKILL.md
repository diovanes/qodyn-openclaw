# Triagem de incidente

## Dados mínimos

- serviço afetado;
- início percebido;
- usuários afetados;
- erro observável;
- mudança recente;
- workaround.

## Saída

1. Impacto.
2. Evidências.
3. Hipóteses rotuladas.
4. Ação reversível.
5. Próximo responsável.
6. Critério de encerramento.
